# Banking Management System using MySQL

# Project Description
This project is a simple Banking Management System developed using MySQL.

# Technologies Used
- MySQL
- SQL

# Database Tables
- Customers
- Accounts
- Transactions

# SQL Concepts Covered
- CREATE and INSERT
- SELECT, WHERE and ORDER BY
- JOINs
- GROUP BY and HAVING
- Aggregate functions
- Subqueries
- UPDATE
- COMMIT and ROLLBACK

# Learning Objective
This project helps practice SQL queries and understand basic banking database operations using sample data.
